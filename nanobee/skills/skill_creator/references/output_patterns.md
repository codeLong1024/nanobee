# 输出模式参考

模板和示例模式，用于技能中定义输出的格式和质量标准。

## 表格输出

结构化数据的标准输出格式。

```markdown
## 汇总报告

| 文件名 | 状态 | 行数 | 错误 |
|--------|------|------|------|
| data.csv | ✅ 完成 | 1,234 | 0 |
| report.docx | ✅ 完成 | 56 | 0 |
| broken.xlsx | ❌ 失败 | - | 格式不支持 |

## 说明
- 文件名：输入文件的路径
- 状态：处理是否成功
- 行数：处理的数据行数
- 错误：错误信息（如有）
```

## 代码示例输出

展示代码时保持清晰和可执行。

````markdown
## 示例脚本

```python
# scripts/rotate_pdf.py
import PyPDF2

def rotate_pdf(input_path: str, output_path: str, degrees: int = 90) -> None:
    """旋转 PDF 页面。"""
    with open(input_path, "rb") as f:
        reader = PyPDF2.PdfReader(f)
        writer = PyPDF2.PdfWriter()
        for page in reader.pages:
            page.rotate(degrees)
            writer.add_page(page)
        with open(output_path, "wb") as out:
            writer.write(out)
```
````

## 多选一输出

当有多种方案时，让用户选择。

```markdown
## 可选方案

请选择处理方式（回复序号即可）：

1. **转成 Markdown** — 保留格式，输出为 .md 文件
2. **提取纯文本** — 丢弃所有格式，仅保留文字
3. **提取表格** — 单独提取文档中的所有表格
4. **全部导出** — 同时输出以上三种格式
```

## 输出设计原则

1. **先结论后细节** — 用户最需要的信息放最前面
2. **结构化优先** — 表格、列表强于段落文字
3. **可操作性强** — 包含后续步骤选项，不留给用户死胡同
4. **错误信息友善** — 说明原因 + 建议解决方案，而非仅仅报错
5. **一致性** — 同一技能的不同输出使用相同的格式风格
6. **避免信息过载** — 信息量大时使用渐进式披露（折叠/摘要）
